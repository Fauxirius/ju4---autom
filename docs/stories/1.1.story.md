# Story 1.1: Update Build Configuration for Modernization

## Status
InProgress

## Story
**As a** Developer,
**I want** the project's build configuration to be updated to the modernized technology stack,
**so that** I can build the application with Java 17, Spring Boot 3.2.5, and prepare for JUnit 5 migration.

## Acceptance Criteria
1.  The `<java.version>` property in `pom.xml` must be set to `17`.
2.  The `spring-boot-starter-parent` version in `pom.xml` must be `3.2.5`.
3.  All PowerMock dependencies (`powermock-module-junit4`, `powermock-api-mockito2`) must be completely removed from `pom.xml`.
4.  The `spring-boot-starter-test` dependency must be configured to exclude the legacy `junit-vintage-engine`.

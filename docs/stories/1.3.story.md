# Story 1.3: Migrate Test Suite

## Status
InProgress  

## Story
**As a** Developer,
**I want** to migrate the existing test suite from JUnit 4/PowerMock to JUnit 5/Mockito,
**so that** the tests are compatible with the modernized tech stack and follow current testing best practices.

## Acceptance Criteria
1. `PowermockApiApplicationTests.java` must not contain any imports from `org.junit.Test`, `org.junit.runner`, or `org.powermock`.
2. The test class must be annotated with `@SpringBootTest`.
3. The `NotificationUtil` dependency must be mocked using the `@MockBean` annotation.
4. The test method must use JUnit 5's `@Test` annotation (`org.junit.jupiter.api.Test`).
5. The test must verify that `notificationUtil.sendNotification` is called exactly once using `Mockito.verify()`.

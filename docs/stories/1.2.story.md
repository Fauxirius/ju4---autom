# Story 1.2: Refactor Production Code

## Status
InProgress

## Story
**As a** Developer,
**I want** to refactor the production code to eliminate static dependencies,
**so that** it aligns with modern dependency injection principles and can be tested without PowerMock.

## Acceptance Criteria
1. `NotificationUtil.java` must be refactored from a class with `static` methods into a Spring `@Service`.
2. The `sendNotification` method in `NotificationUtil` must be an instance method, not a static one.
3. `OrderService.java` must use constructor-based dependency injection to receive a `NotificationUtil` instance.
4. `OrderService.java` must call the instance method `notificationUtil.sendNotification(...)` instead of the static `NotificationUtil.sendNotification(...)`.

## Tasks / Subtasks
- [x] Task 1: Refactor `NotificationUtil.java` (AC: 1, 2)
  - [x] Subtask 1.1: Add the `@Service` annotation to the `NotificationUtil` class.
  - [x] Subtask 1.2: Remove the `static` keyword from the `sendEmail` method signature. (Note: method name was `sendEmail` in code).
- [x] Task 2: Refactor `OrderService.java` (AC: 3, 4)
  - [x] Subtask 2.1: Add a `private final NotificationUtil notificationUtil;` field to the `OrderService` class.
  - [x] Subtask 2.2: Create a public constructor for `OrderService` that accepts a `NotificationUtil` instance and assigns it to the field.
  - [x] Subtask 2.3: Update the `checkoutOrder` method to call `this.notificationUtil.sendEmail(...)` instead of the static method.
- [x] Task 3: Address `javax` to `jakarta` namespace changes.
  - [x] Subtask 3.1: Identify and replace any `javax.*` imports with their `jakarta.*` equivalents in the modified files. (Note: No `javax` imports were found in the scope of this story).
- [x] Task 4: Verify Compilation
  - [x] Subtask 4.1: Run `mvn compile` to ensure the refactored production code compiles successfully. (Tests are still expected to be broken).
